# Pattern Ladder

Graded daily practice of English sentence patterns, from beginner to advanced,
following the 25 verb patterns and usage notes of A. S. Hornby's
*A Guide to Patterns and Usage in English*. All examples and exercises are original.

- The app: `www/index.html`
- Build steps: see `HOW-TO-MAKE-THE-ANDROID-APP.md`
- Every push to `main` builds an installable APK (see the **Actions** tab).
